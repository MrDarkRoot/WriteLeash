Fix accidental WooCommerce price overwrites

These guides are the repair, not a product tour. Use the export or the product screen named in the guide. You do not need a plugin to follow them.

Revised 2026-11-10. Search volume for these tasks was not measured.

  • Undo a WooCommerce bulk price edit from the pre-change CSV

    Restore the old prices from a CSV taken before the bulk edit. Do not reverse a percentage cut with the same percentage.

  • Restore WooCommerce sale prices a CSV import overwrote

    Put the old sale prices back from the pre-import export. On the mapping screen, set every other column to Do not import.

  • An imported WooCommerce sale is saved but the shop shows full price

    If the variation already shows the sale, do not import prices again. Update one variable product and check the shop.

  • Stop staff and AI tools from changing WooCommerce prices

    Take away product-edit access, and revoke REST keys and application passwords you do not trust. Core has no price-only role.

  • Keep a WooCommerce price history with a dated CSV

    Save a dated CSV of ID, SKU, regular price, sale price, and both sale dates before the next bulk change.

WriteLeash 0.3.0 previews a price change and can undo eligible prices it applied. It will not undo a bulk edit or import that already ran, and it is not a firewall. The directory listing is WriteLeash on WordPress.org. The source is the WriteLeash repository.
